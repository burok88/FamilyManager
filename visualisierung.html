Struktur, Prozesse, Personen und Aufgaben im Haushalt

Interaktive Ansicht des Ontologie-Modells: erst das abstrakte Schema (Knoten- und Kantentypen), dann die Beispieldaten eines Musterhaushalts — inklusive echtem Müllkalender als Anwendungsfall für "wer ist wann für welche Tonne zuständig".

Die sechs Grundbegriffe

PersonFamilienmitglied, z.B. Ben.
StrukturOrt: Haushalt, Küche, Garten.
AufgabeTätigkeit, z.B. Müll rausbringen.
ProzessBündelt Aufgaben zu einer Routine.
TerminKonkretes Datum, keine Regel.
RessourceZusatzobjekt, z.B. eine Tonnenart.
Aus dem echten Müllkalender: der Buchstabe allein reicht nicht — "C" steht je nach Farbe für drei verschiedene Tonnen. Der Code ist also Farbe + Buchstabe: schwarzes C = Restmüll, braunes B = Biotonne, gelbes C = Gelber Sack, grünes C = Papiertonne. Termine werden deshalb als konkrete Datumsknoten gespeichert, nicht als Wiederholungsregel.

Momentaufnahme von digest.py — pro Person alle Aufgaben, deren Termin innerhalb ihrer individuellen Vorlaufzeit liegt. Genau dieses JSON ist die Schnittstelle für eine KI oder Home Assistant.
